# Warden Browser (Beta)

A clean, performance-focused Android web browser powered by Mozilla GeckoView.

Warden Browser aims to provide a fast and fluid core browsing experience away from unnecessary bloat. It uses GeckoView (the Firefox engine) instead of Chromium WebView.

</div>

---

## Features

- Fast page rendering powered by GeckoView (Firefox engine)

- URL or search query input from the address bar with selectable search engines (Google, DuckDuckGo, Brave, Bing)

- Speed dial home screen

- Browsing history with one-tap clearing

- Incognito mode — separate session, no history saved

- JavaScript toggle, desktop mode, theme selection (light/dark/system)

- Material Design interface with edge-to-edge layout
